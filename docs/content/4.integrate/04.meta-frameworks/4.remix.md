Client-only editor — [Meta SSR](/integrate/basics/meta-ssr). `@codemerge/integrate/remix` is an alias of `/react` (`CodeMergeEditor`).

```tsx
import { useState } from 'react';
import { CodeMergeEditor } from '@codemerge/integrate/remix';

export default function PageEditor() {
  const [html, setHtml] = useState('<p></p>');
  return <CodeMergeEditor value={html} format="html" onChange={setHtml} />;
}
```

Mount only in a client route / `ClientOnly` boundary — same rules as [React](/integrate/frontend/react). Packs / upload: [Host config](/integrate/basics/host-config). Load/save: [Persistence](/integrate/basics/persistence).
