# Rust Loco

On-Codemerge in the browser; Loco stores **HTML** (or Markdown) in your app database — the editor itself is a normal frontend bundle.

## Install

```bash
npm install on-codemerge
```

## Editor (what matters)

Build the editor with Vite (or your bundler) and wire it like any SPA:

```js
import { Editor, createCorePlugins } from 'on-codemerge';
import 'on-codemerge/index.css';
import 'on-codemerge/public.css';

const editor = new Editor(document.getElementById('editor'), {
  plugins: createCorePlugins(),
});

const { html } = await fetch('/api/doc').then((r) => r.json());
editor.setHTML(html ?? '<p>Hello from Loco</p>');

editor.on('docChanged', () => {
  fetch('/api/doc', {
    method: 'PUT',
    headers: { 'content-type': 'application/json' },
    body: JSON.stringify({ html: editor.getHTML() }),
  });
});
```

### Where the HTML lives

| Piece       | Loco convention                                                              |
| ----------- | ---------------------------------------------------------------------------- |
| Editor UI   | `frontend/` (Vite) → built assets copied or referenced from `assets/static/` |
| Load/save   | Loco controller + route, e.g. `GET/PUT /api/doc` returning `{ "html": "…" }` |
| Persistence | Model column (`html` text) or file field — not the kernel JSON               |

Loco runs Axum under the hood; static hosting and JSON handlers follow the same pattern as [Rust Axum](./rust-axum.md), with routes/controllers generated by Loco’s CLI.

### Extract

```js
const html = editor.getHTML();
const md = editor.getMarkdown();
```
